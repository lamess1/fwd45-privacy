# Fwd45 privacy policy site

Static GitHub Pages site for the privacy notice for **Was ich dich fragen wollte**.

## Publication status

The public page is available at <https://lamess1.github.io/fwd45-privacy/>. Its technical descriptions are based on the current app implementation and RevenueCat's publicly available privacy and DPA documents.

Before using the page as the App Store privacy-policy URL, Fwd45 must confirm that its RevenueCat agreement and active project configuration match the described subprocessors, retention, and international transfers, and obtain final legal review of the policy and App Store privacy answers.

The page is intentionally self-contained and does not load external fonts, analytics, or scripts.

## GitHub Pages

GitHub Pages is configured to deploy from the root of the `main` branch. The optional custom domain `datenschutz.fwd45.com` is not configured; the `github.io` URL above is already public and served over HTTPS.

The repository contents and published page are public. Do not store credentials, customer data, or other private files here.
